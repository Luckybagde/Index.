# Photos folder

Put your two photographs here, using these EXACT file names:

| File name                 | Where it appears            | Suggested shape        |
|---------------------------|-----------------------------|------------------------|
| `girlfriend-photo.jpg`    | "Our Little World" — left   | Tall / portrait (4:5)  |
| `couple-photo.jpg`        | "Our Little World" — right  | Wide / landscape (3:2) |

## How to add them

1. Open this folder: `LuckyVishuWebsite\images`
2. Copy your two photos into it.
3. Rename them exactly `girlfriend-photo.jpg` and `couple-photo.jpg`
   (Windows may hide the `.jpg` part — if the file is named
   `girlfriend-photo.jpg.jpg`, rename it to just `girlfriend-photo.jpg`).
4. That's all. The code is already pointing at these names — no editing needed.

You can also send photos over WhatsApp/Google Drive to the folder above;
just make sure the names match.

## Notes

- Until a photo exists, the frame shows a soft romantic placeholder with the
  expected file name — a broken-image icon never appears.
- Any photo size works: the frame crops it neatly to fit.
- Keep each photo under about 2 MB so the page stays quick to load.
- `.jpg` is what the site asks for. If your photo is a `.png` or `.heic`,
  either convert it to `.jpg`, or ask and the code can be switched to `.png`.
- Never delete this README — GitHub needs the folder to exist before the
  photos are added.
